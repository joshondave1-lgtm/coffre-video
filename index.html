Coffre vidéo

Protège le lien de ta vidéo derrière un code. Aucun serveur : tout est chiffré directement dans ton navigateur.

Comment ça marche : ce fichier fonctionne seul, sans Claude ni connexion à un serveur. Envoie-le une fois à la personne (par mail, clé USB, etc. — elle peut le réutiliser pour toutes tes prochaines vidéos). Pour chaque vidéo, envoie-lui aussi le paquet et le code, séparément. Avec le paquet seul ou le code seul, impossible d'accéder à la vidéo.

Envoie le lien ci-dessus à la personne, puis donne-lui le code par un autre moyen (SMS, appel...). Le lien ne s'ouvrira correctement que si ce fichier est hébergé en ligne (ex. GitHub Pages) ou si la personne ouvre exactement ce même fichier depuis son appareil.
